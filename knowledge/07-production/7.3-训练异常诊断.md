# 7.3 训练异常诊断：reward 不涨 / KL 爆炸 / 长度坍缩 / 熵坍缩

## 一句话
把 [[6.6-指标与评估体系]] 的指标和 [[7.2-调参经验库]] 的对策串成"症状→指标确认→根因定位→修复"的诊断流程，遇到训练异常能系统性排障而非乱试。

## 核心公式/原理

### 通用诊断四步
```
① 症状确认：哪个指标异常？（reward/KL/entropy/长度/acc）
② 文本验证：看 rollout dump，模型真实输出是什么？（曲线会骗人，文本不骗人）
③ 根因定位：对照下面的决策树，定位是数据/reward/参数/算法问题
④ 修复验证：改一个变量，重跑确认指标恢复
```

### 异常 1：reward 不涨（最高频）
```
看 reward 曲线平 + val acc 平
├─ 看 rollout dump：模型输出有 #### 吗？
│   ├─ 没有/格式乱 → 格式问题：prompt 指令不清 / base 模型不会该格式
│   │   → 先 SFT 教格式，或调 prompt 指令
│   └─ 格式对但答案错 → 能力问题：任务太难 / base 太弱
├─ 开 num_examine 看打分：该得分的得了吗？
│   └─ 打分错 → reward 函数 bug（最常见！）→ 修 compute_score
├─ 看优势：全 0？
│   └─ GRPO 组内全对或全错 → 数据难度两极 → 换中等难度 / temperature↑
└─ 看 KL 与 lr：KL≈0 且 lr 很小 → 没在学 → lr 适当↑
```
> [!warning] 第一嫌疑人永远是 reward 函数
> "reward 不涨"80% 是 reward 打分 bug（抽取错、比对错、单位错）。开 num_examine 打印几条 [prompt/response/ground_truth/score] 人工核对，比调任何参数都快。

### 异常 2：KL 爆炸（策略跑偏）
```
KL 曲线突然飙升 + 可能 reward 异常升 + 语言退化
├─ 根因 A：lr 太大 → lr ↓
├─ 根因 B：kl_loss_coef 太小，约束不住 → kl_loss_coef ↑
├─ 根因 C：reward 有漏洞，模型疯狂钻 → 看 rollout dump 是否 hacking（[[6.4-reward hacking]]）
└─ 确认 kl_loss_type=low_var_kl（k1/k2 估计不稳会误导）
```
> 处理优先级：先看是否 hacking（文本），再调 lr/kl。

### 异常 3：长度坍缩（response 变得极短）
```
response 长度骤降 + acc 可能降
├─ 根因 A：长度惩罚过重 → 模型"摆烂"给最短答案 → 降低长度惩罚
├─ 根因 B：reward 只奖励"答对"且短答案易得 → 检查 reward 设计
└─ 根因 C：熵坍缩伴随 → 见异常 4
```
> 区分"长度坍缩（过短）"与"长度暴涨（[[6.4-reward hacking]]）"——方向相反，对策相反。

### 异常 4：熵坍缩（entropy→0，response 趋同）
```
entropy 持续下降接近 0 + 组内 response 越来越像 + pass@k 降
├─ 根因 A：clip 下限把探索压死 → DAPO clip-higher（提高上限）
├─ 根因 B：数据太简单，组内全对，优势全 0 → DAPO dynamic sampling 过滤全对/全错组
├─ 根因 C：temperature 太低 → temperature ↑
└─ 根因 D：entropy_coeff=0 且无探索激励 → 给很小正值
```
> [!important] 熵坍缩是 GRPO 长训的大敌
> 熵坍缩后模型失去多样性，GRPO 组内样本趋同 → 优势估计退化 → 训练停滞。DAPO 的 clip-higher + dynamic sampling 就是专门为治它设计的（[[2.6-算法对比]]）。

### 异常 5：grad_norm 异常
```
grad_norm 持续 >> clip_grad（1.0）
├─ 梯度爆炸倾向 → lr↓、检查数据是否有异常样本、warmup
grad_norm 长期 ≈0
└─ 梯度消失 / 优势全 0 → 查 reward 是否恒定、组内是否无差异
```

### 异常速查总表
| 症状 | 关键确认指标 | 最可能根因 | 首选修复 |
|---|---|---|---|
| reward 平 | 打分（num_examine） | reward 函数 bug | 修 compute_score |
| KL 爆 | KL 曲线 | lr 大 / kl 小 / hacking | lr↓ kl↑ 查文本 |
| 长度暴涨 | 长度曲线 | 长度 hacking | 长度惩罚 |
| 长度坍缩 | 长度曲线 | 惩罚过重 | 降长度惩罚 |
| 熵坍缩 | entropy | clip/数据简单 | clip-higher / DS |
| 震荡 | reward 曲线 | lr 大 / batch 小 | lr↓ batch↑ |
| 全 0 优势 | grad_norm≈0 | 组内无差异 | 调难度/temperature |
