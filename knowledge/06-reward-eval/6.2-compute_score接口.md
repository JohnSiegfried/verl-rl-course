# 6.2 compute_score 接口：签名、参数与返回值

## 一句话
自定义 reward 只需写一个函数 `compute_score(data_source, solution_str, ground_truth, extra_info)`，返回 float 或带 `"score"` 的 dict——verl 会按 `data_source` 把每条样本路由给对应打分函数。

## 核心公式/原理

### 函数签名（逐字）
```python
def compute_score(data_source, solution_str, ground_truth, extra_info=None):
    """
    data_source:  str  — 数据集名（路由依据，来自 parquet）
    solution_str: str  — 模型生成的 response 文本
    ground_truth: str  — 参考答案（来自 parquet 的 reward_model.ground_truth）
    extra_info:   dict — 额外元信息（可选）
    return: float  或  dict（至少含 "score" 键，可带其他指标）
    """
```

> [!important] 返回值两种形式
> - **float**：直接当 reward。
> - **dict**：`{"score": float, "acc": ..., "format_ok": ...}` —— `"score"` 是 reward，其余键会进 `reward_extra_info` 用于观测（[[6.6-指标与评估体系]]）。返回 dict 能让你同时记录多个子指标。
> 来源：verl reward_score 接口（default_compute_score 归一化：dict 原样返回，int/float/bool 转 float，tuple 取 [0]）。

### 最小自定义示例
```python
# my_reward.py
def compute_score(data_source, solution_str, ground_truth, extra_info=None):
    # 例：奖励更长的回答（封顶 1.0）
    return min(len(solution_str) / 100.0, 1.0)
```
```bash
python3 -m verl.trainer.main_ppo \
    reward_model.custom_reward_function.path=/path/to/my_reward.py \
    reward_model.custom_reward_function.name=compute_score \
    ...
```

> [!tip] 命名小技巧
> - 只测一个函数：直接命名 `compute_score`，可省略 `custom_reward_function.name`（verl 默认找它）。
> - 测多个函数：都放一个文件，用 `custom_reward_function.name` 区分，方便脚本化多组实验。
> 来源：verl reward_function.rst。

### 一个实战级数学 reward（带格式 + 部分分 + dict 返回）
```python
import re

def compute_score(data_source, solution_str, ground_truth, extra_info=None):
    # 1. 抽 #### 后的答案
    m = re.search(r"####\s*(\-?[0-9\.\,]+)", solution_str)
    format_ok = m is not None
    if not format_ok:
        return {"score": 0.0, "acc": 0, "format_ok": 0}
    pred = m.group(1).replace(",", "").strip()
    gt = str(ground_truth).replace(",", "").strip()
    # 2. 比对
    try:
        correct = abs(float(pred) - float(gt)) < 1e-6
    except ValueError:
        correct = (pred == gt)
    score = 1.0 if correct else 0.1   # 对=1，格式对但错=0.1
    return {"score": score, "acc": int(correct), "format_ok": 1}
```

> 返回 dict，训练时就能在日志里同时看到 reward、acc（正确率）、format_ok（格式率）三条曲线——这对 [[6.6-指标与评估体系]] 至关重要。

### data_source 路由机制（多数据集混训）
verl 的 `default_compute_score` 是个**分发器**，按 `data_source` 路由到具体打分器：

| data_source | 路由到 |
|---|---|
| `openai/gsm8k` | `reward_score.gsm8k` |
| `lighteval/MATH` 等 | `reward_score.math` |
| `math_dapo`, `aime*` | `reward_score.math_dapo` |
| `numina_*` | `reward_score.prime_math` |
| `codecontests`/`apps`/`taco` | `reward_score.sandbox_fusion`/`prime_code` |
| `hiyouga/geometry3k` | `reward_score.geo3k` |
| 其他 | `NotImplementedError`（需自定义） |

> [!warning] 混训多数据集时
> 你的自定义 `compute_score` 会**覆盖**默认路由。要混训，需在函数内自己按 `data_source` 分支：
> ```python
> def compute_score(data_source, solution_str, ground_truth, extra_info=None):
>     if data_source == 'openai/gsm8k': ...
>     elif data_source == 'my/code': ...
> ```

### 批处理版（可选，提吞吐）
若样本量大，可实现 batch 版一次算多条：
```python
def compute_score_batch(data_sources, solution_strs, ground_truths, extra_infos=None):
    return [compute_score(ds, s, g, e) for ds, s, g, e in
            zip(data_sources, solution_strs, ground_truths, extra_infos)]
```
