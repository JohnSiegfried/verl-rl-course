# 6.6 指标与评估体系：reward / 长度 / KL / entropy / grad_norm / val acc

## 一句话
一套完整的 RL 评估体系 = **算法健康指标**（reward/KL/entropy/grad_norm）+ **能力指标**（val acc/pass@k）+ **行为指标**（response 长度/格式率）——三者一起看，才能分清"真变好"与"假象"。

## 核心公式/原理

### 指标体系三层
```
① 算法健康（训练稳不稳）
   reward、KL、entropy、grad_norm、clip 比例、actor/critic loss
② 能力（模型变没变好）
   val acc、pass@k、avg@k、benchmark 分（GSM8K/MATH/AIME）
③ 行为（模型在怎么变）
   response 长度、格式正确率、重复率、思考长度
```

### 核心指标逐个讲

**reward（最核心但最易误读）**
- 含义：平均奖励。应该**总体上升**。
- 误读：reward 升 ≠ 能力升（可能 hacking，[[6.4-reward hacking]]）。必须配合 val acc 看。
- 健康形态：稳步上升后趋于平台。

**KL 散度（防跑偏）**
- 含义：当前策略离参考模型多远（[[2.3-KL正则]]）。
- 健康形态：**缓慢上升**（策略在合理范围探索）。
- 异常：突然飙升 → 策略突变（lr 太大 / kl_loss_coef 太小）；一直为 0 → 没在学。

**entropy（探索度）**
- 含义：策略分布的熵，越高越"多样"，越低越"确定"。
- 健康形态：缓降（模型变确定是收敛的正常现象）。
- 异常：**坍缩到接近 0** → 熵坍缩，response 趋同、失去多样性（DAPO clip-higher 可缓解，[[2.6-算法对比]]）。

**grad_norm（梯度健康）**
- 含义：梯度范数，被 `clip_grad`（默认 1.0）裁剪。
- 异常：持续 >> clip 阈值 → 梯度爆炸倾向（数据/lr 问题）；长期为 0 → 梯度消失/优势全 0（GRPO 组内全对全错）。

**actor loss / critic loss**
- actor loss：policy 目标，围绕 0 小幅波动正常（clip 后）。
- critic loss（PPO）：应下降并稳定；GRPO 无此项。

**val acc / pass@k（能力真相）**
- 在隔离的 val 集上的正确率/通过率（[[6.5-评测集构建]]）。
- **这是判断"是否真变好"的最终依据**，优先级高于 reward。

**response 长度（行为信号）**
- 平均长度、长度分布。
- 异常：持续暴涨 → 长度 hacking；骤降到很短 → 可能在逃避作答。

### 指标组合诊断表（核心交付）
| reward | val acc | KL | 长度 | 判断 | 对策 |
|---|---|---|---|---|---|
| ↑ | ↑ | 缓升 | 稳定 | ✅ 健康学习 | 继续 |
| ↑ | 平/降 | — | 暴涨 | ⚠️ 长度 hacking | 加长度惩罚 |
| ↑ | 降 | 飙升 | — | ⚠️ 跑偏/hacking | kl_loss_coef↑，lr↓ |
| 平 | 平 | ≈0 | — | ⚠️ 没在学 | 查 reward 函数是否打错、lr 是否太小、优势是否全 0 |
| 震荡 | — | — | — | ⚠️ 不稳 | lr↓、batch↑、grad clip |
| — | — | entropy→0 | 趋同 | ⚠️ 熵坍缩 | clip-higher / entropy_coeff / temperature↑ |

> [!tip] 这套表是 [[7.3-训练异常诊断]] 的基础
> 把上表内化成"看曲线直觉"：每次训练先看 reward+val acc 是否同向，再扫 KL/entropy/长度有没有异常。

### verl 日志里的指标名
- `critic/score/mean`：平均 reward（规则/RM 分）
- `actor/kl_loss`、`actor/entropy`、`actor/grad_norm`、`actor/ppo_kl`
- `response_length/mean`：平均 response 长度
- `val/...`：验证集指标
- `perf/...`：吞吐（tokens/s）、各阶段耗时（[[7.1-性能调优]]）

> 具体指标名随 verl 版本略有差异，以 `trainer.logger` 输出为准。
