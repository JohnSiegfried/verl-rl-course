# 5.4 verl 并行映射：tp_size / fsdp_config / megatron_config / ulysses

## 一句话
verl 把 [[5.1-并行原语]] 落到几个具体配置项上：**训练端**选 FSDP 或 Megatron（`strategy` + 对应 config），**rollout 端**用 vLLM 的 `tensor_model_parallel_size`，**长序列**叠加 `ulysses_sequence_parallel_size`——理清它们各管哪一端，就不会配错。

## 核心公式/原理

### verl 里"两套并行"的对应关系
verl 的 actor 有**训练态**和**推理态**（[[3.6-3D-HybridEngine]]），并行配置也分两套：

| 端 | 配置项 | 对应并行 |
|---|---|---|
| **训练** | `actor.strategy=fsdp` + `actor.fsdp_config.*` | FSDP（DP+ZeRO3 分片） |
| **训练** | `actor.strategy=megatron` + `actor.megatron.*` | Megatron（TP/PP/SP） |
| **Rollout** | `rollout.tensor_model_parallel_size` | vLLM TP |
| **长序列** | `actor.ulysses_sequence_parallel_size` | Ulysses SP |

> [!important] 最容易混淆的一点
> `rollout.tensor_model_parallel_size`（vLLM 推理 TP）和 Megatron 训练的 `tensor_model_parallel_size` **是两个独立参数**，分别控制"采样时的推理并行"和"训练时的模型并行"。两者数值可以不同（权重靠 reshard 转换布局）。
> 来源：verl 配置说明 + 3D-HybridEngine。

### 训练端：FSDP 配置
```yaml
actor_rollout_ref.actor.strategy: fsdp
actor_rollout_ref.actor.fsdp_config:
  param_offload: False        # 参数是否卸 CPU
  optimizer_offload: False    # 优化器是否卸 CPU
  fsdp_size: -1               # 分片组大小，-1=全部 DP 卡
  # forward_prefetch: True    # 前向预取（通信藏计算，见 7.1）
```
- FSDP 的"并行度"= DP 卡数 = `world_size`（不额外设 tp/pp）。
- 每卡显存 ≈ $16P/N$，$N$=world_size（[[5.2-FSDP原理]]）。

### 训练端：Megatron 配置
```yaml
actor_rollout_ref.actor.strategy: megatron
actor_rollout_ref.actor.megatron:
  tensor_model_parallel_size: 4      # TP
  pipeline_model_parallel_size: 2    # PP
  sequence_parallel: True            # SP
  # virtual_pipeline_model_parallel_size: ...  # 交错流水减气泡
```
- 总并行度 = TP × PP × DP，需 `world_size = TP × PP × DP`。
- 例：16 卡，TP=4、PP=2 → DP=2。

### Rollout 端：vLLM TP
```yaml
actor_rollout_ref.rollout.tensor_model_parallel_size: 2
```
- 每个 vLLM 实例用 TP=2 卡；`world_size / tp` = vLLM 副本数（DP）。
- **约束**：`world_size % tp == 0`，否则 DP 组非整数（[[3.5-batch体系]] 报错速查）。
- 小 TP → 更多副本 → DP 吞吐更高，但 KV cache 更多（[[7.1-性能调优]]）。

### 长序列：Ulysses SP
```yaml
actor_rollout_ref.actor.ulysses_sequence_parallel_size: 4
```
- 把序列切 4 份，配 `use_remove_padding=True` + fused kernels。
- 何时用：`max_response_length` 很大（如 8K/16K/32K）导致激活/KV 显存爆炸时。

### 一个完整并行映射案例（16 卡集群）
> 目标：训 14B 模型，FSDP 训练 + vLLM rollout。
> - 训练：`strategy=fsdp`，world_size=16 → 每卡训练态 $16×14/16 ≈ 14$ GB。
> - Rollout：`rollout.tensor_model_parallel_size=2` → 8 个 vLLM 副本。
> - 长 CoT：`ulysses_sequence_parallel_size=2`（若 response 长）。
> 显存核对用 [[5.5-分布式显存重分配]] 的公式。

### 选型决策
```
模型 ≤7B 且单机？
  └─ FSDP（strategy=fsdp，最简单）
模型 8B–30B 或要多机？
  ├─ 求快上手 → FSDP + 多机
  └─ 求极致性能/MoE → Megatron(TP+PP+SP)
response 很长（>8K）？
  └─ 叠加 ulysses_sequence_parallel_size
rollout 慢？
  └─ 调小 rollout.tensor_model_parallel_size（更多副本）
```
