# 5.3 Megatron 原理：TP/PP/SP 切分与 FSDP 的取舍

## 一句话
Megatron 用**模型并行**（TP 切权重矩阵 + PP 切层 + SP 切序列）把超大模型切到多卡，每层内靠高效 NVLink 通信，是训练百亿~千亿模型的性能利器，但要求模型代码专门适配。

## 核心公式/原理

### TP：张量并行的数学（以 MLP 为例）
MLP 两个矩阵 $Y = \text{GeLU}(XA)\,B$，$A\in\mathbb{R}^{h\times f}$、$B\in\mathbb{R}^{f\times h}$：

- **A 按列切**（column parallel）：$A=[A_1|A_2]$，每卡算 $\text{GeLU}(XA_i)$，得 $f/2$ 维。
- **B 按行切**（row parallel）：$B=\begin{bmatrix}B_1\\B_2\end{bmatrix}$，$Y = \text{GeLU}(XA_1)B_1 + \text{GeLU}(XA_2)B_2$，最后 **all-reduce 求和**。

> [!note] 为什么一列一行搭配
> 列并行产生"部分维度"，正好喂给行并行"按维切分"的输入，中间**无需通信**；只在最后 all-reduce 一次。这样每个 MLP 只通信一次（前向）+ 一次（反向）。Attention 同理：QKV 按列、输出投影按行。
> 来源：Megatron-LM 论文。

### PP：流水线并行与气泡
- 把 $L$ 层切成 $pp$ 段，激活段间 p2p 传递。
- **气泡**：流水线启动/排空时部分卡空闲，气泡占比 $\approx \frac{pp-1}{m}$（$m$=micro-batch 数）。
- 解法：**1F1B 调度**（one-forward-one-backward）+ 足够多 micro-batch 把气泡摊薄。

### SP：Megatron 式序列并行
- TP 已把 LayerNorm/Dropout 之外的激活按 $h$ 切了；但 LayerNorm/Dropout 仍按全序列存激活。
- Megatron-SP 把**这些非 TP 算子的激活沿序列维**切 $sp$ 份，省长序列激活。
- 与 [[5.1-并行原语]] 的 Ulysses-SP 思路不同（Ulysses 切 head 用 all-to-all），但都为省长序列激活。

### Megatron vs FSDP 怎么选
| 维度 | FSDP | Megatron |
|---|---|---|
| 并行哲学 | 数据并行 + ZeRO-3 分片 | 模型并行 TP+PP+SP |
| 通信频率 | 层粒度 all-gather（中等） | TP 每层 all-reduce（高） |
| 跨机扩展 | 好（通信少） | TP 限单机，跨机靠 PP+DP |
| 模型适配 | **几乎零改动**（HF 直接包） | 需用 Megatron 版模型实现 |
| 超大 MoE | 一般 | **更优**（专家并行 EP） |
| 上手成本 | 低 | 高 |
| 极致性能 | 中 | **高** |

> [!tip] verl 里的取舍
> - **快速上手 / 中等模型（≤14B）/ 要 LoRA** → 选 **FSDP**（本课程主线）。
> - **超大模型 / MoE / 追求极致 MFU / 已有 Megatron 版模型** → 选 **Megatron**。
> - verl 正从旧 workers 架构迁到统一 `engine` 抽象，FSDP/Megatron 后端可插拔（[[3.1-单控制器架构]] 解耦红利）。

### verl 中的 Megatron 关键配置
```yaml
actor_rollout_ref.actor.strategy: megatron
actor_rollout_ref.actor.megatron.tensor_model_parallel_size: 4
actor_rollout_ref.actor.megatron.pipeline_model_parallel_size: 2
actor_rollout_ref.actor.megatron.sequence_parallel: True
# 依赖 apex + transformer-engine + megatron-core（见 1.2 环境搭建）
```

> [!warning] Megatron 的额外门槛
> 需要 `apex`、`transformer-engine`、`megatron-core` 精确版本（[[1.2-环境搭建]]），且模型要有 Megatron 实现（verl 在 `verl/models/llama` 提供 llama/qwen/deepseek 等）。RL 中 Megatron 训练态与 vLLM 推理态的权重 reshard 比 FSDP 更复杂（[[3.6-3D-HybridEngine]]）。
