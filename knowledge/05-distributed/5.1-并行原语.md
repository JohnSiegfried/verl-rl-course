# 5.1 并行原语：DP / TP / PP / SP(Ulysses) / CP 数学含义与通信量

## 一句话
大模型放不进单卡，就用五种并行把它"切开"：DP 切数据、TP 切权重矩阵、PP 切层、SP/CP 切序列；每种切法对应不同的显存节省与通信代价，选哪种取决于瓶颈在哪。

## 核心公式/原理

### 总览对比表
| 并行 | 切什么 | 显存节省 | 主要通信 | 通信时机 |
|---|---|---|---|---|
| **DP** 数据并行 | batch 维度 | 不省权重（每卡全量） | 梯度 all-reduce | 每步反向后 |
| **TP** 张量并行 | 权重矩阵（按行/列） | 权重 /tp | all-reduce 激活 | 每层前向/反向内 |
| **PP** 流水线并行 | 层（depth） | 权重 /pp | 激活 p2p | 层间边界 |
| **SP** 序列并行(Ulysses) | 序列维度 | 激活 /sp | all-to-all | attention 前后 |
| **CP** 上下文并行 | 序列维度 | 激活/KV /cp | ring all-gather KV | attention 内 |

### DP（Data Parallel，数据并行）
- **切法**：每卡持完整模型副本，各算 batch 的一部分，反向后 all-reduce 梯度求均值。
- **显存**：权重/优化器**不省**（每卡一份），所以纯 DP 只能训"单卡装得下"的模型。
- **通信量**：每步 all-reduce 梯度，量 = 参数量 $P$（与 batch 无关）。
- 朴素 DP 的进化就是 ZeRO / FSDP（[[5.2-FSDP原理]]），把权重/优化器也切了。

### TP（Tensor Parallel，张量并行）
- **切法**：把权重矩阵按行或列切到多卡。如 MLP 的 $Y=XW$，$W\in\mathbb{R}^{h\times f}$ 按列切成 $tp$ 份，每卡算 $f/tp$ 维，再 all-reduce 拼回。
- **数学**：列并行 $W=[W_1|W_2]$，$XW=[XW_1|XW_2]$；行并行需 all-reduce 求和。
- **显存**：权重 /tp，但**激活不省**（每卡要全量输入 X）。
- **通信**：每层 2 次 all-reduce（前向+反向），通信频繁 → TP 通常**限制在单机内**（NVLink 高带宽）。

### PP（Pipeline Parallel，流水线并行）
- **切法**：把 $L$ 层切成 $pp$ 段，每卡只放一段，激活在段间点对点传递。
- **显存**：权重 /pp，激活也只存自己那段的。
- **通信**：仅层间边界传激活（p2p），量小。
- **痛点**：流水线气泡（bubble），用 micro-batch 流水（1F1B）填补。

### SP（Sequence Parallel，Ulysses 序列并行）
- **切法**：把序列 $s$ 切到多卡，每张卡算 $s/sp$ 个 token。attention 需要全序列的 K/V，用 **all-to-all** 在注意力前后交换。
- **显存**：激活 /sp，**长序列训练的救星**。
- **verl**：`ulysses_sequence_parallel_size`，配合 remove_padding / fused kernels。

> [!tip] Ulysses vs Megatron-SP
> verl 的序列并行用 **Ulysses**（all-to-all 交换 head），与 Megatron 的 SP（切 LayerNorm/Dropout 的序列维）思路不同但目标一致：把超长序列的激活切到多卡。详见 [[5.3-Megatron原理]]。

### CP（Context Parallel，上下文并行）
- **切法**：也是切序列，但用 **ring attention**：K/V 沿环状拓扑 all-gather，每卡只算自己那段 Q 对全部 K/V 的注意力。
- **与 SP 区别**：SP 用 all-to-all 重排 head，CP 用 ring 传 K/V；CP 更适合超长上下文 + FlashAttention。

### 通信量量级直觉（$P$=参数量，$s$=序列长，$h$=hidden）
| 并行 | 每步通信量 | 带宽敏感度 |
|---|---|---|
| DP | $P$（梯度） | 中（反向一次） |
| TP | $O(s\cdot h)$ × 层数 × 2 | **高**（每层多次）→ 限单机 |
| PP | $O(s\cdot h)$ × 段边界 | 低 |
| SP/CP | $O(s\cdot h)$ × all-to-all/ring | 中高（长序列才用） |

> [!important] 组合策略（企业实践）
> - **单机内**：TP（NVLink 高带宽扛得住每层 all-reduce）。
> - **跨机**：DP/FSDP + PP（通信少）。
> - **长序列**：叠加 SP/CP。
> verl 里训练用 FSDP（DP 的进化）或 Megatron(TP/PP/SP)，rollout 用 vLLM(TP)，见 [[5.4-verl并行映射]]。
