# 3.3 输入数据格式：parquet 5 字段 + chat_template

## 一句话
verl 的训练数据是 parquet 文件，每条样本必须含 **data_source / prompt / ability / reward_model / extra_info** 五个字段；其中 `data_source` 决定用哪个 reward function，`prompt` 是 chat 格式，会被 tokenizer 套用 chat_template。

## 核心公式/原理

### 五个必填字段
| 字段 | 类型 | 作用 |
|---|---|---|
| `data_source` | str | 数据集名。**用于在 RewardManager 中索引对应的 reward function**（如 `openai/gsm8k` → gsm8k 打分器） |
| `prompt` | list[dict] | **HuggingFace chat_template 格式**的对话，如 `[{"role":"user","content":"..."}]`。`RLHFDataset` 的 tokenizer 会 apply_chat_template 并分词 |
| `ability` | str | 任务类别（如 `math`），用于统计/分组 |
| `reward_model` | dict | 评测用，主要用其 `ground_truth` 子字段。**注意：reward function 的实现必须与这个 ground_truth 的提取方式对齐** |
| `extra_info` | dict | 记录当前 prompt 的元信息（split/index），暂不参与训练 |

> [!warning] ground_truth 对齐陷阱
> `reward_model.ground_truth` 由你的 `extract_solution` 函数从原始答案中抽出。**打分函数里怎么比对，提取时就要怎么抽**——比如 GSM8K 抽 `####` 后的数字，打分器就按数字比对；抽错了格式，reward 全错。
> 来源：verl Prepare Data 文档。

### GSM8K 预处理完整示例
```python
import re, datasets

def extract_solution(solution_str):
    # 抽取 "#### " 之后的最终答案
    solution = re.search("#### (\\-?[0-9\\.\\,]+)", solution_str)
    assert solution is not None
    final = solution.group(0).split('#### ')[1].replace(',', '')
    return final

instruction_following = 'Let\'s think step by step and output the final answer after "####".'
data_source = 'openai/gsm8k'

def make_map_fn(split):
    def process_fn(example, idx):
        question = example.pop('question') + ' ' + instruction_following
        answer = example.pop('answer')
        solution = extract_solution(answer)
        return {
            "data_source": data_source,
            "prompt": [{"role": "user", "content": question}],
            "ability": "math",
            "reward_model": {"style": "rule", "ground_truth": solution},
            "extra_info": {"split": split, "index": idx},
        }
    return process_fn

# 主流程：加载 → map → 存 parquet
dataset = datasets.load_dataset(data_source, 'main')
train = dataset['train'].map(make_map_fn('train'), with_indices=True)
test  = dataset['test'].map(make_map_fn('test'),  with_indices=True)
train.to_parquet('train.parquet'); test.to_parquet('test.parquet')
```
> 来源：verl Prepare Data 文档（GSM8K 示例，逐字）。

### 从 parquet 到初始 DataProto
```
parquet 一行
  │  prompt (chat 格式)
  ▼  tokenizer.apply_chat_template + 分词
DataProto.batch:      input_ids, attention_mask, position_ids, prompts
DataProto.non_tensor: data_source, reward_model(ground_truth), ability, extra_info
  │
  ▼  进入 [[3.4-数据流转全链路]] 的 rollout
```

### 关键数据参数（启动脚本里配）
| 参数 | 含义 | 注意 |
|---|---|---|
| `data.train_files` / `data.val_files` | 训练/验证 parquet 路径 | 可多个 |
| `data.train_batch_size` | **全局** prompt 批大小 | 见 [[3.5-batch体系]] |
| `data.max_prompt_length` | prompt 最大 token 数 | 超长截断/过滤 |
| `data.max_response_length` | response 最大 token 数 | 影响 KV cache 显存 |
| `data.filter_overlong_prompts` | 是否过滤超长 prompt | 防 OOM |
| `data.truncation` | 截断策略（'error'/'left'/'right'） | 'error' 遇超长报错 |
