# 2.4 优势估计：GAE、reward-to-go、RLOO、组内相对优势

## 一句话
优势函数 $\hat{A}_t$ 回答"这个动作比平均好多少"，是策略梯度的权重；不同算法的核心差异几乎都在"如何估计优势"——PPO 用 GAE（需要 critic），GRPO 用组内相对优势（不需要 critic）。

## 核心公式/原理

### 优势函数的定义
$$A(s_t, a_t) = Q(s_t, a_t) - V(s_t)$$
- $Q(s_t,a_t)$：在 $s_t$ 做 $a_t$ 后的期望回报
- $V(s_t)$：在 $s_t$ 按策略行动的期望回报（基线）
- $A>0$：此动作优于平均；$A<0$：劣于平均

verl 通过 `algorithm.adv_estimator` 选择估计方法，常用取值：`gae`（PPO）、`grpo`、`rloo`、`reinforce_plus_plus`、`remax` 等。

### 方法 1：reward-to-go（最朴素）
用"从 $t$ 到结束的回报"当优势，不要 critic：
$$\hat{A}_t = G_t = \sum_{t'\ge t}\gamma^{t'} r_{t'}$$
- 优点：无偏、不需要 critic。
- 缺点：方差极大（[[2.1-RL基础与策略梯度]] 提到的问题）。

### 方法 2：GAE（Generalized Advantage Estimation，PPO 标配）
GAE 用 critic 学的 $V(s)$ 做基线，并用 TD 误差的指数加权平均平衡偏差与方差：
$$\hat{A}_t^{GAE(\gamma,\lambda)} = \sum_{l=0}^{\infty}(\gamma\lambda)^l \delta_{t+l}, \quad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$
- $\lambda$：偏差-方差权衡旋钮（0→纯 TD 低方差高偏差；1→蒙特卡洛高方差低偏差）。
- **需要 critic 网络**（学 $V$）→ 额外显存 + 训练不稳定因素。
- verl 配置：`algorithm.adv_estimator=gae`，配 `critic` 模型 + `trainer.critic_warmup`。

### 方法 3：RLOO（REINFORCE Leave-One-Out）
对同一 prompt 采样 $n$ 个 response，用**其余 $n-1$ 个的平均回报**当基线：
$$\hat{A}_i = r_i - \frac{1}{n-1}\sum_{j\ne i} r_j$$
- 不需要 critic，靠"组内其他样本"当基线减方差。
- 已经是"组内相对比较"的思想，是 GRPO 的近亲。

### 方法 4：GRPO 组内相对优势（本课程主线）
对同一 prompt 采样一组 $G$ 个 response（这就是 `rollout.n`），用**组内回报的 z-score 归一化**当优势：
$$\hat{A}_i = \frac{r_i - \text{mean}(\{r_1,\dots,r_G\})}{\text{std}(\{r_1,\dots,r_G\})}$$

> [!important] GRPO 优势的三个关键性质
> 1. **不需要 critic**：基线就是组内均值，省掉整个 critic 网络的显存与训练麻烦。
> 2. **组内归零和**：$\sum_i \hat{A}_i \approx 0$，天然形成"好的上升、差的下降"的相对压力。
> 3. **每个 token 共享同一优势**：一条 response 的所有 token 用同一个 $\hat{A}_i$（序列级优势），与 PPO 的逐 token GAE 不同。
> 来源：GRPO 论文（见关键来源）。

> [!warning] 为什么 GRPO 必须 rollout.n > 1
> 优势来自"组内对比"，组大小 = `rollout.n`。若 `n=1`，组内只有一个样本，mean=它自己，优势恒为 0，学不到东西。**做 GRPO 务必把 `actor_rollout_ref.rollout.n` 设为 >1**（官方示例 n=5）。
> 来源：verl GRPO 示例注释（见关键来源）。

### 四种方法对比
| 方法 | 需要 critic | 显存 | 方差 | 适用 |
|---|---|---|---|---|
| reward-to-go | 否 | 最低 | 极高 | 教学/玩具 |
| GAE | **是** | 高（多一个 critic） | 低 | PPO，通用 RLHF |
| RLOO | 否 | 低 | 中 | 组采样任务 |
| **GRPO** | 否 | **低** | 中低 | **数学/代码 RLVR** |
